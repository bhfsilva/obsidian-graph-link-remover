🇧🇷 **pt-BR:**

Plugin simples do Obsidian para ocultar links entre arquivos na visualização de grafos.

Feito para uso pessoal.

A condição padrão para que um link seja ocultado é a do texto de exibição dele terminar com `.` (ponto). \
Para alterar essa condição, apenas edite o método [`removable(graphLink)`](https://github.com/bhfsilva/obsidian-graph-link-remover/blob/20a274e24a0147933e5ec7e1063b12ace353d546/main.js#L13C5-L13C25) da classe `GraphLinkRemover`.

🇺🇸 **en-US:**

Simple Obsidian plugin to hide links between files in graph view.

Made for personal use.

The default condition for a link to be hidden is that its display text ends with `.` (period). \
To change this condition, only edit the [`removable(graphLink)`](https://github.com/bhfsilva/obsidian-graph-link-remover/blob/20a274e24a0147933e5ec7e1063b12ace353d546/main.js#L13C5-L13C25) method in `GraphLinkRemover` class.
